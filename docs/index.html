First run

Windows will warn you

All Block isn't code-signed — a certificate costs more than this app makes, which is nothing. SmartScreen flags anything unsigned, so you get this once. Here's the way through it.

  1. Click “More info” The warning says Windows doesn't recognise the publisher — not that it found anything wrong.
  2. Click “Run anyway” The button only appears after the first step.
  3. Click “Yes” on the admin prompt Admin is what lets All Block hold the input lock against everything else. Without it, some of the blocking is skipped.
