FAQ

Questions

What if I really need to get out?

Use an emergency escape. You get one a month free, three on Pro, and they refill on the 1st. On Windows, hold Esc for five seconds on the lock screen. On the phone, tap Emergency escape. An extra escape costs £0.99.

What still works on my phone?

Calls, the dialer and contacts. Everything else waits for the timer.

Does restarting end a block?

No. It comes back locked, with the time that was left.

What if Windows locks during a block?

Sign in as usual. The block carries on, and the clock keeps its time.

Windows warned me about the download.

The All Block is not code-signed yet, so SmartScreen warns about it. Click More info, then Run anyway, then Yes on the admin prompt.
